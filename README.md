# Spatial Context Theory

**Why Visual Views Solve the Documentation Problem in AI Systems**

By Tony Turner | [SpatialThinking.ai](https://spatialthinking.ai) | January 2025

---

## The Insight

I've spent 30 years building systems that scale - from an ISP I grew in a garage to £6M ARR, to leading 56 engineers as VP Engineering at Napster.

I use tools like Claude Code every day. They're genuinely mind-blowing.

But I'm curious about something. The labs have the brightest minds on the planet. Yet I don't see any of them focused on Human-AI *collaboration*. They're building AI that replaces humans, not AI that works *with* humans.

And nobody seems to have spotted that documentation is the disaster at the heart of it all.

Documentation fails not because of discipline problems, but because of architecture problems. When documentation is a parallel artifact, it always degrades. When documentation is generated from visual structure, it cannot degrade.

I had no option but to take a different path. I'm outside the labs - I couldn't focus on context windows or models. So I focused on the collaboration problem instead.

This is Spatial Context Theory.

---

## The Four Problems Solved

1. **The Black Box Problem** - Visual structure is observable by both humans and AI. No hidden state.
2. **The Guessing Problem** - Context is structurally defined through explicit code pointers, not inferred.
3. **The Context Problem** - Views scope context precisely. Pass the "Leaf," not the "Forest."
4. **The Scaling Problem** - Structure scales; error rates stay flat even as complexity explodes.

---

## How It Works: The 2-Minute Workflow

Humans provide Intent. AI provides Speed. We should only do what we are best at.

### Step 1: The Big Picture (The Map)

A High-Level View shows your entire architecture - every module, every relationship. This is your navigation. It prevents system-level hallucinations by giving the AI the same map you see.

### Step 2: The Little Picture (The Lasso)

When you need a feature, you drill into a Sub View - say, the auth module. Now you're at the right level of granularity. You Lasso the relevant components (shift-click, select all, whatever feels natural), and create your feature.

You and the AI chat for 2 minutes to align on intent - the UX nuance, the edge cases.

### Step 3: The Self-Fulfilling Loop

This is the magic. The AI takes over. It updates the State, writes the Feature Doc, and - as it builds - it enriches the context. It updates metadata, pointers, and file links automatically.

The result? The map is self-healing. As the AI builds, the context gets stronger, not noisier.

- The Human provides the "What"
- The AI ensures the "How" is documented and current
- No more stale READMEs
- No more tribal knowledge
